OrgVolution – Website-Mockup (Stand 02.11.2026)

Inhalt
- index.html   Startseite (Deutsch)
- en-*.html    Englische Fassung jeder Seite (en-index.html = englische Startseite);
               Flaggen-Button oben rechts wechselt die Sprache
- *.html       Unterseiten (Angebote, Workshops, Events, Perspektiven inkl. Artikel und Videos,
               Arbeitsweise, Über uns, Organisationen entwickeln, Impressum …)
- img/         Fotos, Logos, Teamfotos, Kundenfotos, Artikelbilder, Logo-Animation

Ansehen (lokal)
- ZIP entpacken und index.html im Browser öffnen. Kein Server nötig.

Online stellen (statisches Hosting, z. B. Netlify Drop, Vercel, GitHub Pages oder eigener Webspace)
- Den kompletten Ordner "orgvolution-website" hochladen; index.html muss im Wurzelverzeichnis liegen.
- Ordnerstruktur nicht verändern.

Offene Platzhalter
- Buchung: Google-Kalender-Einbettung in erstgespraech.html eintragen (Block BUCHUNG), Datenschutz
- Impressum: Rechtsgrundlagen (TMG/RStV) auf DDG/MStV aktualisieren
- Kundenstimmen Purpose, Ziele, Metrics auf "Strategie und Ausrichtung" (Block KUNDENSTIMMEN am Ende der Datei)
- Event-Daten, Ergebnis im Fallbeispiel Green Fusion
- Stations-Logos aller Personen außer Samir Keck, Teamrollen prüfen
- Mockup-Whitepaper in Perspektiven (Datenblock PERSPEKTIVEN in perspektiven.html)

Vor dem Livegang
- Variantenseiten entfernen: fuehrungskraefte-entwickeln-umschalter.html, fuehrungskraefte-entwickeln-sprungleiste.html,
  ueber-uns-team-2.html, ueber-uns-team-3.html (und die Variantenleisten auf den Hauptseiten)
- workshop-vorlage.html ist eine Vorlage, nicht verlinkt.
- Schrift (Quicksand) wird von Google Fonts geladen.
